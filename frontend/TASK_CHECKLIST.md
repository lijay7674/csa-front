## 关键设计决策记录

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 框架 | 纯 HTML/CSS/JS | 设计原型阶段，快速验证视觉效果 |
| CSS 方案 | CSS Variables + data-theme | 原生支持，无构建依赖，切换流畅 |
| 粒子动效 | Canvas 2D | 性能好，支持复杂动画（花瓣/代码雨） |
| 响应式 | CSS Grid + @media | 桌面优先，768px/480px 断点 |
| 滚动动效 | Intersection Observer | fadeInUp，性能优于 scroll 事件监听 |

## 当前项目结构

```
csa-frontend/                    ← React + TypeScript + Vite + Tailwind
├── packages/
│   ├── web/                     ← 前台展示官网 (React 18 + Vite)
│   │   └── src/
│   │       ├── pages/           Home, News, Register, Placeholder
│   │       ├── components/      PublicHeader, PublicFooter, ParticleCanvas
│   │       ├── context/         ThemeContext (四主题状态管理)
│   │       ├── hooks/           useScrollReveal
│   │       └── router/          React Router v6 路由
│   └── shared/                  ← 共享类型+常量
│       └── src/                 types, constants
│
frontend/                        ← 静态原型（保留参考）
    ├── index.html, news.html, register.html
    └── css/theme.css
```
